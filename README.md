# Insight Agency

Site vitrine et portfolio de **Insight Agency**, projet indépendant orienté analyse de données et solutions web.

## À propos

Insight Agency présente des services de :

- analyse de données et statistiques
- création et maintenance de sites web
- accompagnement sur des projets numériques simples (formulaires, bases de données, documents)

Le site sert de vitrine, de portfolio et de point de contact.

## Stack

- PHP
- HTML / CSS
- Base de données (formulaires et contenus)

À adapter si le projet utilise d’autres outils (JavaScript, GitHub Pages, hébergement mutualisé, etc.).

## Installation locale

1. Cloner le dépôt.
2. Placer les fichiers dans le dossier web de ton serveur local (par exemple `htdocs` avec XAMPP, ou le document root de ton hébergeur).
3. Créer la base de données et importer le fichier SQL s’il existe.
4. Renseigner les identifiants de connexion dans le fichier de configuration (ne pas commiter les mots de passe).
5. Ouvrir le site dans le navigateur, par exemple `http://localhost/insight-agency`.


Adapter les noms de dossiers à l’arborescence réelle du projet.
